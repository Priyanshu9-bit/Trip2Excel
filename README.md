# Trip2Excel

A React-based transport report tool that turns loosely formatted transport notes into structured Excel reports.

## Features

- Paste transport notes or upload a TXT file
- Detect dates, vehicle numbers, ticket numbers, routes, rates, and detention charges
- Preview and edit extracted values
- Calculate totals and summary figures
- Export the report as an `.xlsx` file

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.


https://trip2-excel-hnv9.vercel.app/
